# BD103's Personal Tap

This is a collection of Homebrew formula and casks that I use personally.

## How do I install these formulae?

```bash
# Shorthand
brew install bd103/tap/<formula>

# Or...
brew tap bd103/tap
brew install <formula>
```

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "bd103/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
